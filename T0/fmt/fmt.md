# fmt (format)

## 一、 打印与格式化：四大函数族

按**输出目标**分为四组，每组包含普通打印（无换行）、带换行（`ln`）、格式化（`f`）三种变体：

| 函数族 | 输出目标 | 变体特点 |
| --- | --- | --- |
| `Print` / `Println` / `Printf` | `os.Stdout` | **无后缀**：默认格式；两操作数都不是字符串时加空格 |
| `Sprint` / `Sprintln` / `Sprintf` | 返回 `string` | **`ln` 后缀**：操作数之间总加空格，末尾加 `\n` |
| `Fprint` / `Fprintln` / `Fprintf` | 写入 `io.Writer` | **`f` 后缀**：按格式化动词（verb）和标志（flag）解析 |
| `Append` / `Appendln` / `Appendf` | 追加到 `[]byte` | 适合复用字节切片、减少内存分配 |

## 二、 常用格式化动词（Verbs）

### 1. 通用类（General）

* `%v`：默认格式；结构体加 `%+v` 会输出字段名。
* `%#v`：Go 语法风格表示（`±Inf`、`NaN` 按对应字面规则输出；`uint` 族在此下常以 `%#x` 风格体现）。
* `%T`：输出值的 Go 类型。
* `%%`：字面量 `%`，不消耗参数。

### 2. 布尔类（Boolean）

* `%t`：输出 `true` 或 `false`。

### 3. 整数类（Integer）

* `%b`：二进制（base 2）。
* `%c`：Unicode 码点对应的字符（rune）。
* `%d`：十进制（base 10）。
* `%o` / `%O`：八进制（`%O` 带 `0o` 前缀）。
* `%q`：安全转义的单引号 rune 字面量（非法码点会转为 `U+FFFD`）。
* `%x` / `%X`：十六进制，小写 `a-f` / 大写 `A-F`。
* `%U`：Unicode 格式，如 `U+1234`；加 `%#U` 在可打印字符后附带 `'x'`。

### 4. 浮点数与复数（Float & Complex）

* `%b`：无小数的二进制指数科学计数法（类似 `strconv.FormatFloat` 的 `'b'`，如 `-123456p-78`）。
* `%e` / `%E`：科学计数法（小写 `e` / 大写 `E`，指数至少两位）。
* `%f` / `%F`：普通小数点表示，无指数（如 `123.456`）。
* `%g` / `%G`：自动浮点数，指数较大时用 `%e`/`%E`，否则用 `%f`/`%F`；默认会去掉末尾多余的 `0`（加 `#` 保留小数点和尾零）。
* `%x` / `%X`：十六进制浮点表示（带十进制的 2 的幂指数，如 `-0x1.23abcp+20`）。
* **复数**：宽度和精度分别作用于实部和虚部，整体加括号，如 `(1.200000+3.400000i)`。

### 5. 字符串与字节切片（String & `[]byte`）

* `%s`：直接输出原始字节（不转义）。
* `%q`：带双引号、按 Go 语法安全转义的字符串（加 `%#q` 在 `strconv.CanBackquote` 为真时优先输出反引号原始字符串）。
* `%x` / `%X`：每字节两位十六进制（小写 / 大写）。

### 6. 切片与指针（Slice & Pointer）

* `%p`：指针输出 `0x` 开头的十六进制地址；切片 `%p` 输出第 `0` 个元素的地址。
* 指针也可配合 `%b`、`%d`、`%o`、`%x`、`%X` 当作整数格式化。

## 三、 宽度、精度、标志与进阶机制

1. **宽度与精度（按 rune 计算，非字节）**

* 形式：`%[宽度].[精度]动词`，如 `%9.2f`、 `%.2f`、`%9.f`（精度为 `0`）。
* 支持 `*` 动态传参（需为 `int`），如 `fmt.Sprintf("%*s", 5, "hi")`；也支持显式参数索引 `[n]`（1 基），如 `fmt.Sprintf("%[2]d %[1]d", 11, 22)` → `"22 11"`。
* **注意**：对字符串/`[]byte` 的精度是**截断输入长度**（按 rune；但在 `%x`/`%X` 下按字节），而非输出总宽度。

1. **常用标志（Flags）**

* `+`：数字强制带正负号；`%q` 转为 `%+q` 保证仅输出 ASCII。
* `-`：右补空格（左对齐）。
* `#`：替代格式（如 `%#b`、`%#o`、`%#x`、`%#U`、`%#q`、`%#g`）。
* `' '`（空格）：正数留空格占位；十六进制字节输出时字节间加空格（`% x`）。
* `0`：用前导 `0` 填充（数字时在符号之后填充）。

1. **接口与递归陷阱**

* 格式化调用顺序大致为：`reflect.Value` 解包 → `Formatter` → `GoStringer`（仅 `%#v`）→ `error`（`Error()`）→ `Stringer`（`String()`）。
* 在 `String() string` 里直接对自身用 `%v`/`%s` 会导致无限递归，应先转换类型（如 `string(x)`）；结构体**不会**对未导出字段调用 `Error` 或 `String`。
* 类型或参数不匹配时会输出 `%!...` 格式错误提示（如 `%!d(string=hi)`、`%!(EXTRA ...)`、`%!d(MISSING)`）。

1. **输入扫描（`Scan` / `Fscan` / `Sscan` 及 `f` / `ln` 变体）**

* 传入参数必须是**指针**或实现了 `Scanner` 接口的类型。
* `Scan*` 把换行视为空格；`Scanln*` 遇到换行停止且要求结尾有换行或 EOF；`Scanf*` 按格式匹配（`%p`、`%T` 及 `#`、`+` 标志未实现）。
